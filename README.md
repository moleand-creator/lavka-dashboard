# Lavka dashboard — ДЗ 4, курс «Визуализация»

Интерактивный HTML-дашборд заказов пользователя (датасет недели 1, вариант B) на **d3.js v7 + Vue.js 3**, без сборки.

Открыть: https://moleand-creator.github.io/lavka-dashboard/

## Что показывает
- **KPI по месяцам** — количество заказов, сумма трат, средняя скидка: текущее значение (последний месяц в данных), изменение к предыдущему месяцу, спарклайн за 24 месяца.
- **Динамика за последние 24 месяца** — столбчатый график выбранной метрики (клик по KPI-плитке переключает метрику), средняя линия, тултип по месяцу.
- **Потребление по позициям** — топ товаров в штуках или в деньгах, иконки категорий; тултип с количеством, суммой, средней ценой, скидкой и **графиком динамики цены** по месяцам.
- **Категории** — список с основными метриками (заказы, штуки, скидка, средний чек позиции, сумма и доля трат); клик по категории — фильтр.
- **Фильтр по категориям** (мультивыбор) действует на все блоки.

## Структура
```
index.html        — разметка, стили, компоненты Vue и графики d3
lib/              — vue.global.prod.js, d3.min.js (локально, чтобы страница открывалась без CDN)
data/orders.js    — датасет (строки заказов), сконвертирован из xlsx недели 1
```
Метрики считаются по доставленным заказам. Средняя скидка = 1 − Σ(цена со скидкой × кол-во) / Σ(цена без скидки × кол-во).
